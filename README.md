作者：Guangyi Zhao

本仓只存**文字稿**（图档与排版 PDF 不入仓），收两个样板：

## sample-01-noahs-ark/ 《Noah's Ark》绘本

- 文案对照稿-中英.md：24 页正文（英文为上架版，中文为审阅对照）+ 标题页 + 版权页
- 上架资料包-KDP.md：书目信息、定价测算、关键词、详情页文案、AI 内容披露口径

## sample-01-coloring-book/ 《Bible Stories Coloring Book for Kids》涂色书

- 文字汇总.md：标题页、版权页、30 页图题（故事名 + 经文出处）与系列预告页文字（书内除标题与出处外无正文，文字原件散在排版脚本中，此为汇总件）
- 上架资料包.md：书目信息、关键词、类目、定价测算、详情页文案、AI 内容披露口径
